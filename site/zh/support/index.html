Mac 版

Mac 版常见问题与故障排查

设置和日常使用见 Mac 版教程，完整功能见 用户指南（英文）。

KVoice 需要哪些权限？

两个：麦克风，在你按住快捷键时听你说话；辅助功能，把文字放进你正在用的应用（App Store 版只用其中模拟按键的部分）。KVoice 启动时不会请求任何权限，也不需要“输入监控”。没有辅助功能权限时，它照样转写，并把文字复制到剪贴板。如果你的 AI 服务运行在另一台电脑上，macOS 可能还会询问本地网络权限。

系统设置里已经打开了辅助功能，KVoice 却说没有。

macOS 把这个权限绑定在应用的代码签名上。如果应用被一个签名不同的副本替换了（比如从源码构建，或用 cp -R 复制），原来的权限就不再适用。在辅助功能列表里移除 KVoice，再重新添加，然后重新打开 KVoice。

没有插入文字，文字跑到了剪贴板里。

当前应用没有可写入的文本框、文本框是密码框，或者 KVoice 工作时你切换到了别的应用。按 ⌘V 粘贴即可。也可以从菜单里再次插入或复制上次的结果。如果某个应用总是失败，请告诉我们。

第一次听写要等好几分钟。

那是 Core ML 在为你的 Mac 编译模型，每个模型只需一次（在“运行时”卡片里更换处理器后也会重新编译）。之后加载很快。

语音模型下载失败或很慢。

模型从 huggingface.co 下载，推荐的 Whisper 模型约 650 MB，请确认网络能访问这个网站，并留出足够的磁盘空间（其他模型约 220 MB 到 1.7 GB）。每个文件都会和应用内置的清单核对，不匹配的会被拒绝，可以在语音模型里删除后重新下载。在 macOS 26 或更高版本上，Apple Speech 不需要 KVoice 下载任何东西。

没说话却转写出了“Thank you.”

Whisper 有时会在静音时产生这句话。KVoice 会丢弃太安静、不可能有语音的录音。如果还是出现，请在“设置 › 麦克风”里检查麦克风音量。

AI 操作没有效果。

AI 操作默认关闭。点菜单栏图标打开“使用 AI 操作”，并在“设置 › AI 操作”里添加一个配置：本机 Apple 智能（macOS 26 或更高版本，系统设置里需打开 Apple 智能），或兼容 OpenAI 的端点。用“测试当前配置”检查。AI 出错或超时时，KVoice 会插入原始转写，录音条会说明原因。

我的文件在哪里？怎么卸载？

文件在 ~/Library/Application Support/kvoice/（App Store 版在 ~/Library/Containers/io.github.kccarlos.kvoice/Data/Library/Application Support/kvoice/）。用 Homebrew 卸载：brew uninstall --zap --cask kvoice 会连同设置、模型和历史一起删除。手动卸载：退出 KVoice，从“应用程序”删除，删除上面的文件夹，再运行 defaults delete io.github.kccarlos.kvoice。

iPhone 版

iPhone 版常见问题与故障排查

分步设置见 iPhone 版设置教程。iPhone 版界面是英文的，下面保留了应用里的英文名称。

怎么添加 KVoice 键盘？

打开“设置 › 通用 › 键盘 › 键盘 › 添加新键盘…”，选择 KVoice。要用键盘听写，再点 KVoice，打开“允许完全访问”。不打开也能打字。

为什么键盘会打开 KVoice 应用？

iOS 键盘不能使用麦克风，所以由 KVoice 应用替键盘录音。点键盘上的麦克风，KVoice 打开并开始听，你返回原来的应用，文字会打在你离开的位置。之后几分钟内，键盘可以直接开始下一次听写（“Settings › Keep listening for the keyboard”，选 Off 可关闭）。

键盘显示 Allow Full Access to dictate。

键盘听写需要完全访问。打开“设置 › 通用 › 键盘 › 键盘”，点 KVoice，打开“允许完全访问”，然后回来再点麦克风。完全访问只用于让键盘和这台 iPhone 上的 KVoice 应用通信，你输入的内容不会被保存或发送。

怎么设置操作按钮？

打开“设置 › 操作按钮”，滑到“控制”，选择 KVoice › Toggle Dictation。按一下开始听写，再按一下结束，文字会复制到剪贴板，KVoice 键盘打开时还会直接打出来。没有操作按钮的 iPhone，可以把 Toggle Dictation 放进控制中心、锁定屏幕，或用“轻点背面”。

按操作按钮时 KVoice 打开了一下。

KVoice 会尽量在后台开始录音；如果 iOS 不允许，它会短暂打开来开始听写。切回去继续说就行。如果 Toggle Dictation 一直不起作用，可以用快捷指令里的 Record Audio 做一个替代快捷指令，步骤见 iPhone 版设置教程。

为什么麦克风指示灯一直亮着？

KVoice 正在录音，或在一次键盘听写后为键盘保持麦克风就绪。可以在实时活动里点 End，或用键盘上的电源按钮结束，也可以把 Keep listening for the keyboard 设为 Off。

某个 AI 模式显示 Needs AI setup。

这个模式的 AI 服务暂时不能用：Apple 智能未开启或不受支持，或者云端服务还没有 API 密钥。到“Settings › AI formatting”里修复，或者改用 Dictation 模式。

怎么停止向云端服务发送数据？怎么删除数据？

“Settings › Privacy › Stop Sending to（服务名）”会撤回同意，并换回设备上的引擎。删除数据：在“Settings › History”里点 Delete All History，或删除应用；请先在设置里移除 API 密钥，因为 iOS 删除应用后仍会保留钥匙串项目。

怎么报告问题

Mac 版

  1. 在 github.com/kccarlos/kvoice/issues 新建一个 issue。
  2. 写清楚你做了什么、期望发生什么、实际发生了什么，以及出问题的应用名称。
  3. 附上 macOS 版本和 KVoice 版本。在“数据与隐私”里点“复制诊断信息”可以得到一份不含转写文字、密钥和端点路径的摘要，贴进 issue 即可。

iPhone 版

  1. 在 github.com/kccarlos/kvoice-ios/issues 新建一个 issue。
  2. 写清楚你做了什么、期望发生什么、实际发生了什么。
  3. 附上 iPhone 型号、iOS 版本和 KVoice 版本（“Settings › About”）。后台开始录音有问题时，“Settings › About › Diagnostics”里的本地日志会有帮助，日志里没有你说的内容。

请不要在 issue 里贴 API 密钥，或任何你想保密的听写内容。安全问题请按 Mac 版仓库里的 SECURITY.md 私下报告。
