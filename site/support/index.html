KVoice for Mac

Mac: questions and troubleshooting

Setup and everyday use: the Mac tutorial. Every feature: the User Guide.

Which permissions does KVoice need?

Two: Microphone, to hear you while you hold the shortcut, and Accessibility, to put the text into the app you are using (the App Store edition uses only its keystroke part). KVoice asks for neither at launch, and it does not need Input Monitoring. Without Accessibility it still transcribes and copies the text to the clipboard. macOS may also ask about the local network if your AI server runs on another machine.

Accessibility is on in System Settings, but KVoice says it is not.

macOS ties the permission to the app's code signature. If the app was replaced by a differently signed copy (for example a build from source, or a copy made with cp -R), the old permission no longer applies. Remove KVoice from the Accessibility list, add it again, and relaunch KVoice.

Nothing is inserted, and the text is on the clipboard instead.

The app in front did not expose a text field KVoice could write to, the field was a password field, or a different app came to the front. Paste with ⌘V, or insert the last result again from the menu. If a particular app always fails, please report it.

The first dictation takes minutes.

That is Core ML compiling the model for your Mac, once per model and after changing the processor in the Runtime card. Later loads are fast.

A speech model download fails or is slow.

Models come from huggingface.co; the recommended Whisper model is about 650 MB. Check that the network can reach that site and that there is disk space (other models range from about 220 MB to 1.7 GB). Every file is checked against a manifest in the app and refused if it does not match; delete the model in Speech Models and download it again. On macOS 26 or later, Apple Speech needs no download from KVoice.

The transcript says “Thank you.” when I did not speak.

Whisper sometimes produces this on silence. KVoice discards recordings that are too quiet to contain speech. If it still happens, check the microphone level in Settings › Microphone.

AI Actions do nothing.

AI Actions are off by default. Switch on Use AI Actions from the menu-bar icon, and add a configuration in Settings › AI Actions: Apple Intelligence on the Mac (macOS 26 or later, with Apple Intelligence turned on in System Settings) or an OpenAI-compatible endpoint. Check it with Test Active Configuration. If the AI fails or times out, KVoice inserts the original transcript and the recorder says why.

Where are my files, and how do I uninstall?

Files live in ~/Library/Application Support/kvoice/ (for the App Store edition, ~/Library/Containers/io.github.kccarlos.kvoice/Data/Library/Application Support/kvoice/). With Homebrew, brew uninstall --zap --cask kvoice also removes settings, models and history. By hand: quit KVoice, delete it from Applications, delete the folder above, and run defaults delete io.github.kccarlos.kvoice.

KVoice for iPhone

iPhone: questions and troubleshooting

Step-by-step setup: the iPhone setup guide.

How do I add the keyboard?

Settings › General › Keyboard › Keyboards › Add New Keyboard… › KVoice. For dictation from the keyboard, tap KVoice there and turn on Allow Full Access. Typing works without it.

Why does the keyboard open KVoice?

iOS keyboards cannot use the microphone, so the KVoice app records for them. Tap the microphone in the keyboard, KVoice opens and listens, swipe back to your app, and the text is typed where you left off. For a few minutes afterwards the keyboard can start the next dictation without switching apps (Settings › Keep listening for the keyboard; choose Off to turn this off).

The keyboard says “Allow Full Access to dictate”.

Dictating from the keyboard needs Full Access. Open Settings › General › Keyboard › Keyboards, tap KVoice, turn on Allow Full Access, then come back and tap the mic. Full Access only lets the keyboard talk to the KVoice app on this iPhone; what you type is never stored or sent.

How do I set up the Action Button?

Open Settings › Action Button, swipe to Controls and choose KVoice › Toggle Dictation. Press once to start dictating and again to stop; the text is copied, and typed for you when the KVoice keyboard is open. On iPhones without an Action Button, put Toggle Dictation in Control Center, on the Lock Screen or on Back Tap.

KVoice opens for a moment when I press the Action Button.

KVoice tries to start in the background; if iOS refuses, it opens briefly to start listening. Switch back and keep going. If Toggle Dictation never works, make a fallback shortcut with Record Audio; the steps are in the iPhone setup guide.

Why is the microphone indicator on?

KVoice is recording, or it is keeping the microphone ready for the keyboard after a keyboard dictation. End it from the Live Activity or the keyboard's power button, or set Keep listening for the keyboard to Off.

An AI mode says “Needs AI setup”.

The mode's AI provider cannot run: Apple Intelligence is off or not supported, or a cloud provider has no API key. Fix it in Settings › AI formatting, or use Dictation mode.

How do I stop sending to a cloud provider, or delete my data?

Settings › Privacy › Stop Sending to provider withdraws your permission and moves KVoice back to on-device engines. To delete data: Settings › History › Delete All History, or delete the app. Remove API keys in Settings first: iOS keeps Keychain items after an app is deleted.

How to report a bug

KVoice for Mac

  1. Open a new issue at github.com/kccarlos/kvoice/issues.
  2. Say what you did, what you expected, what happened, and which app you were dictating into.
  3. Include your macOS and KVoice versions. Data & Privacy › Copy Diagnostics gives a summary without transcript text, keys or endpoint paths that you can paste in.

KVoice for iPhone

  1. Open a new issue at github.com/kccarlos/kvoice-ios/issues.
  2. Say what you did, what you expected and what happened.
  3. Include your iPhone model, iOS version and KVoice version (Settings › About). For background-start problems, the local log in Settings › About › Diagnostics helps; it holds no transcripts.

Never post API keys, or dictation you want to keep private, in an issue. Report security problems privately as described in SECURITY.md.
