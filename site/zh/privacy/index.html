隐私说明

KVoice 的设计原则是：你的声音和文字留在你的设备上，除非你自己选择发送出去。这一页概括了 Mac 版和 iPhone 版保存什么、可能发送什么，以及发往哪里。完整说明以各应用仓库中的隐私文档为准。

简要版

  • 没有服务器、账号、统计分析、广告或追踪。开发者收不到你的任何数据。
  • 语音在你的设备上转写。音频不会上传，除非你在 iPhone 上自己选择了云端转写服务。
  • AI 是可选的。只有你自己选了在线服务并打开时，那一次的文字（在 iPhone 上用云端转写时还包括音频）才会直接从你的设备发给那个服务，不经过我们。
  • API 密钥留在本地：Mac 版存在只有你的用户账户能读取的文件里，iPhone 版存在 iOS 钥匙串里。
  • 诊断日志只留在设备上，只记录状态和耗时，从不记录你说的内容。

KVoice Mac 版

留在你的 Mac 上的

  • 听写时的音频只在内存里，插入文字后丢弃；除非你打开了保留录音（默认关闭）。
  • 历史记录（默认开启，可关闭）保存在 ~/Library/Application Support/kvoice/ 里，保留多久由你设定；“全部清除”会删除它们。
  • 语音模型、设置和词典都在本机。词典作为提示交给本地语音模型，不会离开 Mac。
  • API 密钥保存在只有你的用户账户能读取的文件里（权限 0600），从不写进设置文件。

可能离开你的 Mac 的

  • 语音模型下载：从 huggingface.co 通过 HTTPS 下载，版本固定在应用里，每个文件都与内置清单核对。请求里不包含你的音频、文字、设置或任何标识。Apple Speech 的语言资源由 macOS 自己下载和管理。
  • AI 操作（默认关闭）：打开后，每次听写的转写文字和操作指令发给你选的引擎。你写的用户档案、以及你为某个操作打开的剪贴板或选中文字，也会一起发送。用本机 Apple 智能时，什么都不会离开 Mac；用兼容 OpenAI 的服务时，只发到你配置的那个端点；私密云计算（仅 App Store 版）由 Apple 的服务器处理，必须你明确选择。
  • 你手动发起的检查：“验证并保存”和“测试当前配置”会向那个引擎发一个简短的固定测试请求（绝不是转写内容）。

AI 操作关闭时，KVoice 的设计是除了下载模型和你手动发起的检查外，不发出任何网络请求。远程端点必须使用 HTTPS；明文 HTTP 只允许 localhost。

KVoice iPhone 版

留在你的 iPhone 上的

  • 录音只在你听写时进行。KVoice 为键盘保持麦克风就绪时，在你开始听写之前不会录下或保存任何内容。默认录音会保存在历史记录里，关闭 Keep audio recordings 后每段录音转写完就删除。
  • 转写和整理后的文字保存在历史记录里，可以限制为 30 天或 7 天，Delete All History 会全部删除。删除应用会删除历史、录音、模式和设置。
  • API 密钥只存在 iOS 钥匙串里，只发给它所属的服务。iOS 删除应用后仍会保留钥匙串项目，所以想彻底删除的话，请先在设置里移除密钥。
  • KVoice 键盘不录音、不联网，也不保存或分享你输入的内容。不打开完全访问时它就是普通键盘；打开后它只和同一台 iPhone 上的 KVoice 应用通信。

可能离开你的 iPhone 的

  • 云端转写（你选择 OpenAI、Groq、Google AI Studio、Google Vertex AI 或你填写的兼容端点时）：每次听写的音频发给那个服务。
  • 云端 AI 整理（你选择 OpenAI、Anthropic、Google AI Studio、Google Vertex AI、Groq、OpenRouter 或兼容端点时）：转写文字和模式指令发给那个服务。
  • 下载：Whisper 模型来自 Hugging Face 上的 WhisperKit 模型仓库，Apple Speech 语言模型来自 Apple。这些下载不包含你的任何听写内容。

第一次发送到云端服务之前，KVoice 会显示服务名称和要发送的内容，并征求你的同意；拒绝的话就留在设备上。随时可以在“Settings › Privacy › Stop Sending to（服务名）”撤回同意。

本网站

本网站是托管在 GitHub Pages 上的静态页面：没有 Cookie、没有统计分析、没有第三方脚本或字体。GitHub 作为托管方可能会出于安全和运维目的记录访问日志，详见 GitHub 的隐私声明。

联系

对隐私有疑问？请在对应仓库开一个 issue：Mac 版，iPhone 版。请不要在 issue 里贴 API 密钥或你想保密的听写内容。
